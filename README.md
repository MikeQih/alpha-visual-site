# Alpha Visual

Studio site for Alpha Visual, an AI-native visual studio in Singapore.

Static HTML, no build step. Netlify publishes the repository root.

| Path | Page |
| --- | --- |
| `/` | Studio homepage (glass shards) |
| `/work/hands/` | Dot-matrix hands |
| `/work/editorial/` | Editorial brand page |
| `/work/cellar/` | Cellar shelf concept |
| `/work/lab/` | Particle lab |
| `/work/archive/` | 3D archive |

Images and figures in the work pages are placeholders drawn in code until real assets replace them.
